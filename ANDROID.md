# Android-приложение на Kotlin

Нативная версия использует Jetpack Compose, без HTML и WebView. Основной модуль — `app`.
Исходный веб-прототип оставлен в корне для сравнения. Изменения Android-интерфейса нужно вносить в Kotlin-файлы.

## Запуск

1. Откройте корень репозитория в Android Studio.
2. Выберите JDK 17 для Gradle в настройках Android Studio.
3. Установите Android SDK Platform 35 через SDK Manager и дождитесь Gradle Sync.
4. Выберите телефон или эмулятор с Android 8.0 (API 26) или новее и нажмите Run для модуля `app`.

Для сборки из PowerShell укажите JDK 17 в `JAVA_HOME`, а Android SDK — через `ANDROID_HOME` или `sdk.dir` в `local.properties`:

```powershell
.\gradlew.bat :app:assembleDebug
.\gradlew.bat :app:testDebugUnitTest
```

По умолчанию APK после успешной сборки: `app/build/outputs/apk/debug/app-debug.apk`.
На этом компьютере в `local.properties` дополнительно задано `build.dir=D:/AndroidDev/builds/SberMobileHack`, поэтому APK находится в `D:\AndroidDev\builds\SberMobileHack\app\outputs\apk\debug\app-debug.apk`. Исходники остаются в репозитории. Это экономит место на `C:` и исключает кириллицу из путей классов JVM-тестов Java 17.
Первая сборка требует интернета для загрузки Gradle и зависимостей.

## Возможности

- Фиолетовая кнопка «Запустить» в шапке Activity.
- Сезонный SVG-шар появляется из центра кнопки, вращается и падает в центр с отскоком.
- Свечение, сезонные частицы и побуквенный вывод предсказания.
- Нажатие на шар повторяет бросок; одинаковые ответы подряд исключены, если доступны разные ответы.
- Шар можно перетаскивать пальцем и бросать: скорость жеста задаёт скорость полёта, гравитация и затухание останавливают шар после отскоков от границ. Нижняя панель не входит в область полёта.
- Шар можно перехватить в полёте. После остановки появляется новое предсказание; во время перетаскивания и полёта автоскрытие приостанавливается. После печати ответа шар остаётся на экране 8 секунд.
- Сильные столкновения сопровождаются короткой вибрацией с интенсивностью, зависящей от скорости удара. При отключённых системных анимациях перетаскивание работает без инерционного полёта.
- Ручной выбор сезона, автоматический сезон из конфигурации.
- Кнопка включения и отключения встряхивания; без акселерометра недоступна.
- Короткая вибрация при запуске и после приземления, если устройство поддерживает её.
- Закрытие шара кнопкой «Скрыть» или системной кнопкой «Назад».
- Учитывается отключение анимации в системных настройках при открытии экрана.
- Карточки доступны для нажатия во время эффекта.

## Файлы

- `MainActivity.kt` — Compose-интерфейс, анимация, отображение SVG, частицы и сценарий предсказания.
- `BallConfig.kt` — проверка JSON, сезоны и выбор следующего ответа.
- `MotionInput.kt` — акселерометр с подпиской только при активной Activity.
- `ThrowPhysics.kt` — гравитация, затухание скорости, отскоки и определение остановки шара.
- `config.json` — общий источник ответов и сезонных настроек; копируется в assets при сборке.
- `assets/` — исходные SVG, упаковываются в приложение без дублирования.

Конфигурация поставляется внутри APK. Для изменения ответов без выпуска новой версии потребуется отдельная загрузка конфигурации с сервера; в этом прототипе её нет.

## Проверка на устройстве

Проверьте запуск на узком экране, все четыре сезона, повторный бросок, скрытие во время печати, работу карточек, поворот экрана и возврат из фона. Встряхивание и вибрацию проверяйте на физическом телефоне.

## Статус проверки

Установлены JDK 17 (Eclipse Temurin), Android SDK Platform 35, Build Tools 34.0.0/35.0.0 и Platform Tools (`adb`).

- `JAVA_HOME`: `D:\AndroidDev\java\jdk-17.0.20.1+1`
- `ANDROID_HOME`: `D:\AndroidDev\sdk`
- `GRADLE_USER_HOME`: `D:\AndroidDev\gradle-cache`

Переменные сохранены для текущего пользователя. После установки откройте новый терминал или перезапустите Android Studio. Исходная Java 8 сохранена; Gradle выбирает JDK через `JAVA_HOME`. Команда `java` может по-прежнему находить Java 8, если она стоит раньше в системном `PATH`.

Для обновления окружения уже открытого PowerShell:

```powershell
$env:JAVA_HOME = [Environment]::GetEnvironmentVariable('JAVA_HOME', 'User')
$env:ANDROID_HOME = [Environment]::GetEnvironmentVariable('ANDROID_HOME', 'User')
$env:GRADLE_USER_HOME = [Environment]::GetEnvironmentVariable('GRADLE_USER_HOME', 'User')
$env:Path = "$env:JAVA_HOME\bin;$env:ANDROID_HOME\platform-tools;$env:Path"
java -version
.\gradlew.bat :app:assembleDebug :app:testDebugUnitTest
```

Для пути проекта с кириллицей включена настройка `android.overridePathCheck=true`. Для JVM-тестов используется UTF-8, а результаты сборки на этом компьютере вынесены в каталог с латинским именем.

Проверка `:app:assembleDebug :app:testDebugUnitTest` завершилась успешно: APK собран, 5 JVM-тестов прошли без ошибок (3 для выбора ответа и 2 для физики броска). Проверка интерфейса, жестов и вибрации на телефоне пока не выполнялась.
