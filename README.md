# СберКот · Трек «Приколы» — прототип

Одностраничный прототип для хакатона «Создаём эмоции» (СберKids): мок-экран приложения и поверх него эффект **«СберКот ловит монетки»** при тряске телефона.

## Что внутри

- Мок главного экрана шириной 360–430 px: аватар-кот, СберКарта с балансом 800,55 ₽, Бонусы Спасибо (123), «Скинуть денег», квадрат «Себе», нижняя панель из 4 вкладок.
- Слой эффекта: `position: fixed`, `pointer-events: none`, `z-index` выше контента; длительность меньше 4 секунд, после окончания слой очищается.
- Датчик тряски (`devicemotion`) с порогом и настройками в объекте `CONFIG`; под картой баланса сыплются монетки, СберКот «ловит» их.
- Fallback: кнопки «Потрясти» (ноутбук/без датчика) и «Включить эффект» (iOS-разрешение).
- Только чистые HTML/CSS/JS в одном файле — без библиотек, CDN, шрифтов с чужих хостов и любых сетевых запросов.
- Кнопки и вкладки работают: слой эффекта `pointer-events: none` не блокирует ввод.

## Как открыть

1. **Десктоп:** двойной клик по `index.html` (Chrome/Safari). Эффект запускается кнопкой «Потрясти».
2. **Телефон:** файл должен открываться по **HTTPS** — GitHub Pages или локальный туннель. Без HTTPS браузер не даст доступ к датчику движения.

## iOS

На iOS 13+ событие тряски требует разрешения: вызывается `DeviceMotionEvent.requestPermission()`, и **только по нажатию пользователя** (кнопка «Включить эффект»). После разрешения появляется и кнопка «Потрясти». Если разрешение отклонено или API нет — работает тот же fallback-режим.

## Что в нативном приложении будет иначе

- **События:** вместо `devicemotion` — нативные API датчиков (CoreMotion на iOS, SensorManager на Android) с калибровкой порога тряски, нативная вибрация (Haptics/`Vibrator`) и биометрия жестов.
- **Контент:** вместо инлайновых SVG и CSS-анимаций — ассеты из CDN: Lottie-анимация СберКота, спрайты и звук пойманной монетки.
- **Эффект:** отдельный слой сцены (Lottie / Reanimated / Flutter CustomPainter) на native-рендере, запуск без DOM и без fallback-кнопки.
- **Дизайн:** настоящая дизайн-система СберKids — фирменные шрифты, иконки, токены цветов и анимация-«эмоция» вместо системных стилей.
