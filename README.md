# Магический шар — Android / Kotlin

Нативная Android-версия находится в модуле `app` и использует Jetpack Compose.
Инструкции по запуску и сборке: [ANDROID.md](ANDROID.md).

Для запуска откройте корень проекта в Android Studio, выберите JDK 17, установите SDK 35 и запустите модуль `app` на телефоне или эмуляторе Android 8.0+.

Ниже сохранено описание исходного веб-прототипа для сравнения. Команда `python3 -m http.server` запускает только веб-версию, а не приложение Kotlin.

## Исходный WebView-прототип

Автономная HTML/CSS/JS демонстрация без библиотек и внешних запросов. SVG-ассеты локальные.

## Запуск
В папке проекта:
```bash
python3 -m http.server 8000
```
Откройте http://localhost:8000

На телефоне в той же Wi-Fi сети откройте `http://IP_КОМПЬЮТЕРА:8000` (потребуется разрешение брандмауэра). Кнопка «Запустить» работает без сенсоров.

## Тестирование
1. Переключите все четыре сезона внизу экрана.
2. Нажмите «Запустить» или на аватар справа сверху.
3. Проверьте появление шара, свечение, текст, сезонные частицы и автоматическое скрытие.
4. Во время эффекта нажмите на «Игры» или «Копилка» — строка статуса должна измениться.
5. Нажмите «Скрыть» во время анимации.
6. На телефоне нажмите «Включить тряску», затем встряхните телефон. На iOS нужен HTTPS и разрешение пользователя; на Android доступ зависит от браузера/WebView.

## Конфигурация
`config.json`: `season` (summer/autumn/winter/spring), `particleCount`, `glowColors`, `answers`. `autoSeason:true` переключает сезон по **локальной дате браузера**. Для серверного управления используйте CDN/сервер, отдающий актуальный `config.json` (с корректным CORS и кэшированием).

## Интеграция
JS API: `window.MagicBall.show()`, `.hide()`, `.setSeason("winter")`, `.enableMotion()`.

Важно: HTML `pointer-events:none` позволяет нажимать на элементы **внутри той же веб-страницы**, но не гарантирует прохождение касаний через нативный WebView к приложению под ним. Прозрачность, порядок слоёв, передача встряхивания и касаний требуют интеграции со стороны хост-приложения. Текущий макет только имитирует его.

## Ограничения
Это демонстрационный прототип, не подключенный к СберKids. Сенсорный сценарий на устройствах не подтверждён. Для продакшена нужны тесты на реальных Android/iOS и в целевом WebView.
